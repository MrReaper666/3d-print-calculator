How the estimate works

The parser reads the mesh's triangles directly from the file and sums signed tetrahedron volumes to get the true enclosed solid volume — the same math a slicer uses internally. Since real prints aren't solid, that volume is scaled by the density factor on the left to approximate shells + infill. Push it toward 100% for solid or high-infill parts, and down toward 15–25% for typical hollow decorative prints.
